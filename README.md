# neko3D

## 開発環境

Visual Studio 2022 の「C++ によるデスクトップ開発」で `3dgp1.sln` を開き、
`Debug | x64` または `Release | x64` でビルド・実行できます。

DxLib は `DxLib.props` で設定しています。PC 内の
`C:\DxLib_VC\Dxlib`（現在は 3.25a）を優先し、そのフォルダーがない場合は
プロジェクト内の `DxLib` を参照します。ヘッダーとライブラリは同じフォルダーから
読み込むため、次回プロジェクトを開いたときも再設定やダウンロードは不要です。

配置先を変更した場合は `DxLib.props` のパスを変更するか、MSBuild の
`/p:DxLibDir="配置先"` で指定してください。
NuGet パッケージがない場合は、ソリューションの「NuGet パッケージの復元」を実行します。

## カメラシステム仕様

### 構成と独立性

| 項目 | 通常カメラ | デバッグカメラ |
| --- | --- | --- |
| クラス名 | `Player_camera` | `Debug_camera` |
| ソース | `15_System/Player_camera.h/.cpp` | `Debug_camera.h/.cpp` |
| Visual Studio の分類 | `15_System` | `AboutDebug` |
| 用途 | ゲーム画面を映す定点カメラ | 開発中にシーンを確認するカメラ |
| 操作 | ImGui またはコードから位置を設定 | マウス・キーボード・ImGui |

両カメラは別クラス・別インスタンスで、位置・注視点をそれぞれ保持します。
デバッグカメラの `SetPosition()` はデバッグ側だけを変更し、通常カメラの座標には影響しません。
既存の `AboutDebug` と `Debug_camera` の名前は維持しています。

### 通常カメラ

- 初期位置は `(400.0f, 400.0f, 400.0f)`。高さは Y 座標の `400.0f` です。
- 初期注視点は原点 `(0.0f, 0.0f, 0.0f)`、上方向は `(0.0f, 1.0f, 0.0f)` です。
- プレイヤーの位置・向きに追従せず、設定した位置に固定します。
- マウス・WASD・Q/E・ホイールによる通常カメラ操作はありません。
- プレイヤー本体の座標・移動・当たり判定の処理は維持しています。

### デバッグカメラの切り替え

Debug ビルドで左 Alt + Enter を押すと、デバッグカメラを開始・終了します。
開始時に、その時点の通常カメラの位置・注視点を値としてコピーします。
その後の移動・回転・座標編集はデバッグ側だけに反映します。
終了すると、保持されている通常カメラの視点へ戻ります。
再び開始した場合も、その時点の通常カメラから視点を取り直します。

デバッグカメラ操作中はプレイヤーの更新を停止します。Release ビルドでは
デバッグ切り替えと ImGui を使用せず、通常カメラで描画します。

| 操作 | 動作 |
| --- | --- |
| 左 Alt + Enter | デバッグカメラの開始・終了 |
| マウス移動 | 視点の回転 |
| W / S | 視線方向へ前進・後退 |
| A / D | 左右移動 |
| Q / E | ワールドの Y 軸方向へ下降・上昇 |
| 左 Shift | 移動速度を 3 倍にする |
| R | デバッグ開始時の視点へ戻す |
| F | プレイヤーの現在位置へ注目する |

F は押した時点のプレイヤー位置を向く操作で、継続的な追従ではありません。
デバッグ移動速度の初期値は `500.0f` です。

### ImGui の座標編集

`Scene view camera` ウィンドウに、現在のカメラが `Fixed` / `Debug` のどちらかを表示します。
`Position (X, Y, Z)` は数値を直接編集できます。

- `Fixed` 表示中：通常カメラの位置だけを変更し、注視点は維持します。
- `Debug` 表示中：デバッグカメラの位置だけを変更し、視線の向きは維持します。
- `Player position`：プレイヤーの X・Y・Z を表示します。
- `Move speed`：デバッグカメラの移動速度を調整します。
- `Reset camera`：通常時は初期位置・注視点へ、デバッグ中は開始時の視点へ戻します。
- `Focus player`：デバッグカメラでプレイヤーに注目します。通常時に押すと、現在の視点からデバッグカメラを開始します。

### GameContext との接続

`Init()` と `Reset()` でカメラを初期化し、`Draw()` で選択中のカメラを DxLib に適用します。
`GetPlayerCamera()` は通常カメラへのアクセス、`GetPlayerPosition()` はプレイヤー座標の取得です。
`GetCameraPosition()` / `GetCameraTarget()` / `GetCameraUp()` は選択中のカメラの値を返します。
`SetCameraPosition()` は選択中のカメラだけを変更します。

### 検証

Debug / Release の x64 ビルド成功を確認済みです。
デバッグ開始時の視点継承、視線の向きの維持、座標編集、移動、リセット、
再切り替え、プレイヤーへの注目を実装コードでテストしています。
